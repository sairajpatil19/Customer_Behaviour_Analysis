
# 🛍️ Customer Shopping Behavior Analysis

## 📌 Overview

This project focuses on cleaning, transforming, and preparing customer shopping behavior data using **Python and Pandas**, followed by loading the processed dataset into **PostgreSQL** for further analysis.

The project demonstrates a practical data analytics workflow:

**Raw CSV Data → Data Cleaning → Feature Engineering → PostgreSQL**

The goal is to transform raw customer shopping data into a structured dataset that can be used for SQL analysis and business intelligence.

---

## 🎯 Project Objectives

- Load and inspect customer shopping behavior data.
- Identify and handle missing values.
- Standardize column names.
- Create meaningful customer segments.
- Transform categorical purchase-frequency information into numerical values.
- Remove redundant columns.
- Load the cleaned dataset into PostgreSQL.
- Prepare the data for further SQL analysis and visualization.

---

## 🛠️ Technologies Used

- **Python**
- **Pandas**
- **PostgreSQL**
- **SQLAlchemy**
- **Psycopg2**
- **Jupyter Notebook**
